🛒 Sistema de Gestão de Pedidos

Interface gráfica para gerenciar pedidos de produtos por setor

✨ Funcionalidades Principais

📊

Carregar Planilha

Importa dados de produtos e setores do Excel

🏢

Selecionar Setor

Escolha o cliente/setor do pedido

🔍

Buscar Produtos

Filtro inteligente por nome ou código

🛍️

Carrinho

Adicione produtos com quantidade

💰

Cálculo Automático

Total calculado em tempo real

💾

Salvar Pedido

Gera e salva automaticamente no Excel

🚀 Instalação e Configuração

1 Instalar Dependências

pip install pandas openpyxl
Nota: No Linux, pode ser necessário adicionar --break-system-packages

2 Executar o Programa

python3 sistema_pedidos.py

📖 Como Usar - Passo a Passo

1 Carregar Planilha

  • Clique no botão "📁 Selecionar Arquivo Excel"
  • Navegue até sua planilha
  • Selecione o arquivo Cópia_de_Sync_Produtos.xlsx
  • Aguarde a mensagem de sucesso

2 Selecionar Setor/Cliente

  • No dropdown "Setor", escolha o cliente desejado
  • Exemplo: 38 - ABRINQ
  • Este será o destino do pedido

3 Adicionar Produtos ao Pedido

Existem 3 formas de adicionar:

  • Forma 1: Duplo clique no produto desejado
  • Forma 2: Selecione o produto → Ajuste quantidade → Clique "➕ Adicionar"
  • Forma 3: Use a busca para filtrar → Selecione → Adicione
Dica: Use a caixa de busca para encontrar produtos rapidamente! Digite "caneta" para ver apenas canetas.

4 Revisar o Carrinho

  • Veja todos os itens adicionados no lado direito
  • Confira código, nome, quantidade, preço e total
  • O total geral é calculado automaticamente
  • Remova itens individuais ou limpe tudo se necessário

5 Gerar e Salvar Pedido

  • Revise o valor total do pedido
  • Clique em "✅ Gerar Pedido e Salvar"
  • O sistema cria um ID único e salva tudo
  • Uma mensagem de sucesso aparecerá
  • O carrinho é limpo automaticamente
Importante: Feche a planilha Excel antes de gerar o pedido para evitar erros de salvamento!

📋 Estrutura da Planilha

Aba: Produtos (entrada)

Campo Descrição
productCode Código único do produto
name Nome/descrição do produto
price Preço unitário
product_id ID interno do produto

Aba: Setor (entrada)

Campo Descrição
CódUnidade Código numérico do setor
items__description Nome do setor/cliente

Aba: Pedido (gerada automaticamente)

Campo Descrição
pedido_id ID único do pedido (8 caracteres)
data Data e hora da criação
cliente Setor/cliente selecionado
supervisora Campo vazio (pode ser preenchido depois)
status "Aguardando aprovação" (padrão)
total_pedido Valor total calculado

Aba: ItensPedido (gerada automaticamente)

Campo Descrição
pedido_id ID do pedido (referência)
codigo Código do produto
produto Nome do produto
qtd Quantidade solicitada
valor_unit Preço unitário
total_item Total do item (qtd × valor_unit)

🗺️ Mapeamento de Campos

Conforme especificação original:

Campo Solicitado Origem
CódClienteImpakto Fixo: 208831
CódProImpakto productCode (Aba Produto)
Item name (Aba Produto)
Qtde Número digitado pelo usuário
$ Unitário price (Aba Produtos)
$ Total Qtde × $ Unitário
Setor CódUnidade (Aba Setor)
SETOR2 items__description (Aba Setor)

💡 Exemplo Prático

Cenário: Pedido de Material de Escritório para ABRINQ

  1. Carregar planilha "Cópia_de_Sync_Produtos.xlsx"
  2. Selecionar setor: "38 - ABRINQ"
  3. Buscar "limpador" → Selecionar "Limpador multiuso 500 ml"
  4. Definir quantidade: 10 unidades
  5. Adicionar ao pedido
  6. Buscar "desinfetante" → Selecionar "Desinfetante lavanda 5 l"
  7. Definir quantidade: 5 unidades
  8. Adicionar ao pedido
  9. Revisar carrinho (2 itens, total calculado)
  10. Gerar Pedido e Salvar

Resultado:

  • Pedido ID: a1b2c3d4 (exemplo)
  • Total: R$ 161,00 (10×6,15 + 5×19,90)
  • 2 itens salvos na planilha
  • Status: Aguardando aprovação

💡 Dicas e Boas Práticas

  • ✅ Sempre feche o Excel antes de gerar o pedido
  • 🔍 Use a busca para encontrar produtos rapidamente
  • ✔️ Confira o total antes de finalizar
  • 💾 Mantenha backups da planilha original
  • 📝 Os pedidos ficam registrados permanentemente
  • 📊 Você pode abrir a planilha depois para revisar ou editar
  • 🎯 O duplo clique é a forma mais rápida de adicionar produtos

🔧 Solução de Problemas

Erro ao carregar planilha

  • Verifique se o arquivo tem as abas "Produtos" e "Setor"
  • As abas "Pedido" e "ItensPedido" serão criadas automaticamente

Erro ao salvar

  • Feche a planilha Excel antes de gerar o pedido
  • Verifique permissões de escrita no arquivo
  • Certifique-se de que o arquivo não está em uso

Programa não abre

  • Verifique se o Python 3 está instalado
  • Execute: python3 --version
  • Instale as dependências: pip install pandas openpyxl
